# ایجنت مدیر پروژه برای GitHub — v1.0.0

این قالب در یک مخزن GitHub نصب می‌شود. از صفحهٔ **Actions → Project Manager Agent → Run workflow** درخواستت را وارد می‌کنی. سه اجرای مجزا انجام می‌شود: برنامه‌ریز، پیاده‌ساز، و بازبین مستقل. نتیجه به شکل **Draft Pull Request** و نظر بازبین تحویل داده می‌شود. ادغام یا استقرار خودکار انجام نمی‌شود.

## نصب

1. فایل‌های `.github/workflows/project-manager.yml` و `AGENTS.md` را در ریشهٔ مخزن کپی کن. اگر از قبل `AGENTS.md` داری، دستورهای این فایل را با دستورهای موجود ادغام کن.
2. در تنظیمات مخزن، Secret با نام `OPENAI_API_KEY` بساز. این کلید OpenAI API است و مصرف آن جدا از اشتراک ChatGPT محاسبه می‌شود.
3. از مسیر **Settings → Actions → General** اجازهٔ ساخت Pull Request توسط GitHub Actions را فعال کن؛ اگر سیاست سازمانی اجازه نمی‌دهد، از GitHub App با دسترسی محدود استفاده کن.
4. Workflow را در شاخهٔ پیش‌فرض قرار بده، سپس از Actions اجرا کن و درخواست پروژه را در کادر `task` وارد کن.

اگر فقط می‌خواهی یک پروژهٔ خاص مانند Video Builder اجرا شود، بهتر است این قالب را داخل مخزن همان پروژه نصب کنیم تا ایجنت‌ها کد و تست‌های واقعی آن را ببینند. برای درخواست چند مخزن مختلف، هر مخزن باید workflow خودش را داشته باشد یا یک GitHub App جدا برای مسیریابی ساخته شود.

## محدودهٔ فعلی

- ایجنت‌ها روی یک مخزن کار می‌کنند؛ برنامه‌ریز درخواست را تحلیل می‌کند، توسعه‌دهنده کد را تغییر می‌دهد و بازبین PR را بررسی می‌کند.
- هر اجرا شاخهٔ جداگانه‌ای می‌سازد. اگر دو درخواست همزمان یک فایل را تغییر دهند، ادغام آن‌ها نیاز به بررسی دارد.
- اگر تغییری ایجاد نشود، PR ساخته نمی‌شود. خروجی برنامه‌ریزی در همان اجرای Actions به‌صورت artifact باقی می‌ماند.
- برای استفاده از AI در GitHub Actions به کلید API نیاز است. اجرای واقعی، دسترسی به مخزن و اجازهٔ ساخت PR بعد از نصب باید در همان مخزن آزمایش شود.
