# AGENTRA v2.0.0 — شرکت ایجنتی جکسون

AGENTRA یک نمونهٔ اجرایی برای مدیریت پروژه‌های کدنویسی در **یک مخزن GitHub** است. جکسون درخواست را دریافت می‌کند، حداکثر سه متخصص متناسب با درخواست تعریف می‌کند، کار هر متخصص را در فراخوانی جداگانه انجام می‌دهد، تغییرات را بررسی می‌کند و در صورت نیاز حداکثر دو دور اصلاح می‌گیرد. خروجی فقط یک **draft pull request** است؛ ادغام و انتشار خودکار انجام نمی‌شود.

## ساختار شرکت

- **مالک:** شما؛ درخواست را در صفحهٔ Actions وارد می‌کنید و PR را تأیید می‌کنید.
- **جکسون، مدیر مرکزی:** تیم و وظیفه‌ها را تعیین، کار را تقسیم و کیفیت را کنترل می‌کند.
- **متخصص‌ها:** نقش‌هایشان برای هر پروژه به‌صورت پویا ساخته می‌شود (مثلاً برنامه‌نویس، مستندساز، تحلیلگر داده).
- **بازرس مستقل:** تغییرات و خواستهٔ اولیه را بررسی می‌کند؛ ایرادها برای اصلاح به متخصص بازگردانده می‌شوند.

## مسیر اجرا

1. فایل‌های این بسته را در مخزن عمومی GitHub قرار دهید (فایل workflow را در `.github/workflows/project-manager.yml`).
2. در Google AI Studio یک API key برای پروژهٔ **Free Tier** بسازید. Billing را فعال نکنید.
3. آن را فقط در `Settings > Secrets and variables > Actions` با نام `GEMINI_API_KEY` ثبت کنید؛ کلید را در Issue، چت یا کد قرار ندهید.
4. در `Settings > Actions > General` اجازهٔ ساخت pull request توسط Actions را فعال کنید.
5. در `Actions > AGENTRA - Jackson > Run workflow` درخواست پروژه را بنویسید.

نیازی به روشن‌بودن کامپیوتر نیست؛ مراحل راه‌اندازی و ثبت درخواست از گوشی نیز قابل انجام‌اند. اجرای استاندارد GitHub Actions در مخزن عمومی رایگان است. مدل پیش‌فرض `gemini-3.5-flash-lite` در Free Tier موجود است، ولی سهمیه و دسترسی آن تابع وضعیت حساب Google است. هنگام محدودیت سهمیه یا نبود کلید، اجرا متوقف می‌شود و خودکار به طرح پولی تغییر نمی‌کند.

**حریم خصوصی:** محتوای انتخاب‌شده از مخزن و درخواست پروژه به Google Gemini فرستاده می‌شوند. فایل‌های حساس، کلیدها، پوشه‌های workflow و فایل‌های env در متن ارسالی و تغییرات خروجی فیلتر می‌شوند، اما این ابزار تضمین امنیتی برای مخزن دارای اسرار نیست؛ فقط در مخزنی اجرا کنید که ارسال کد آن به Google مورد قبول شماست.

**محدودیت‌های نسخهٔ ۲:** فقط همان مخزنی را که workflow در آن نصب است ویرایش می‌کند؛ برای مدیریت چند مخزن، نصب جداگانه یا مجوز GitHub App لازم است. فایل‌های متنی کوچک و متوسط پشتیبانی می‌شوند؛ ویدیو، تصویر و اجرای نرم‌افزارهای بیرونی جزو این نسخه نیستند. اگر بررسی کد یا آزمون شکست بخورد، PR ساخته نمی‌شود و گزارش در خروجی اجرا می‌ماند.

## راه‌اندازی آزمایشی بدون API

`python -m unittest discover -s tests -v` آزمون‌های مسیر، نقش‌ها و چرخهٔ اصلاح را بدون اتصال به Google اجرا می‌کند.
